# idk-dawg Game Project

A beginner-friendly Python game project using Pygame.

## Setup Instructions

1. **Install Python** (if you haven't already)
   - Download from [python.org](https://www.python.org/downloads/)

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the game**
   ```bash
   python main.py
   ```

## What's in here?

- `main.py` - The main game file. This is where the game logic goes.
- `requirements.txt` - Lists all the Python packages this project needs.

## Next Steps

- Check out [Pygame Documentation](https://www.pygame.org/docs/)
- Look for Pygame tutorials on YouTube
- Start modifying `main.py` to make your game!

## Game Ideas to Start With

- **Pong** - Two paddles, a ball bouncing back and forth
- **Snake** - A snake that eats food and grows longer
- **Flappy Bird Clone** - A bird that dodges obstacles
- **Simple Platformer** - A character that jumps and collects items

Have fun! 🎮
